# Alpha Company UI Blueprint v1.0

> Purpose:
>
> Define the wireframes, page layouts, and high-fidelity visual specifications for every primary page of the Alpha Company website.

---

# Design Philosophy

The UI should feel like reading a beautifully engineered product rather than browsing a corporate website.

Every screen should communicate one primary idea.

Every scroll should advance the story.

Navigation should never interrupt the experience.

---

# Global Layout Rules

## Container

Max Width

1280px

---

## Grid

12-column responsive grid

---

## Section Spacing

Desktop

120px

Tablet

96px

Mobile

72px

---

## Vertical Rhythm

Each section occupies approximately one viewport height.

Avoid stacking multiple unrelated ideas within the same viewport.

# High-Fidelity Visual Specifications

## Visual Style

Dark-first interface

High contrast

Architectural composition

Minimal decoration

Premium spacing

Editorial typography

---

## Imagery

Use

* Product screenshots
* Engineering workspaces
* Code on monitors
* Whiteboard sessions
* Abstract geometry
* Network visualizations
* Cloud infrastructure illustrations

Avoid

* Generic office stock photos
* Handshake imagery
* Cartoon illustrations
* Overused AI-generated humans
* Decorative graphics without meaning

---

## Motion Specifications

Page Load

* Fade + upward movement
* 600ms

Section Reveal

* Fade
* TranslateY(40px)
* 700ms

Cards

* Lift
* Scale 1.02
* Border highlight

Buttons

* Arrow slide
* Background brighten

Images

* Scale 1.04

Navigation

* Transparent at top
* Solid background after scroll
* Smooth transition

# Design Approval Checklist

Every page must satisfy the following before development:

* Clear primary objective
* Strong visual hierarchy
* Consistent spacing
* Uses approved design tokens
* Uses approved components
* Responsive on all breakpoints
* Meets accessibility standards
* Motion is purposeful
* One primary CTA per section
* Supports SEO structure
* Reflects Alpha Company design language

---

# Final Principle

A visitor should finish browsing Alpha Company with three impressions:

1. These people are exceptional engineers.
2. They build products with discipline and long-term thinking.
3. I trust them to build important software.
